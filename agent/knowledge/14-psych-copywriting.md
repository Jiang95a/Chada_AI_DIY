## 三条硬规则

1. **不承诺疗效**：「治愈」「疗愈」「摆脱」「告别」全部禁用。活动不是治疗。
2. **不给人贴标签**：「社恐来集合」「i 人专属」这种话看着像共情，实际是在替人下定义。
3. **不用感叹号堆情绪**：一行最多一个，最好零个。心理类内容的语气是"平稳"，不是"热烈"。

## 标题：从「喊话」改成「邀请」

| ❌ 不要 | ✅ 改成 |
|---|---|
| 拒绝内耗！做更好的自己！ | 周三晚上，来坐一会儿 |
| 治愈你的不开心 | 一个可以什么都不用说的下午 |
| 你是否正在被焦虑困住？ | 最近睡不着的话，可以来聊聊 |
| i 人社交自救指南 | 小桌制聊天，不用轮流发言 |

判断标准：**这个标题如果是发给一个状态很差的同学，他会不会觉得被冒犯？** 会，就重写。

## 正文：把「你会得到什么」换成「会发生什么」

普通活动文案讲收益（"提升领导力""收获友谊"），心理活动讲**过程**：

- ❌「参加后你会更了解自己」
- ✅「两个小时，前半小时一起定规则，然后两人一组聊十分钟，最后各自说一句」

过程可预期，人才敢来。

## 去污名化用词表

| 别说 | 说 |
|---|---|
| 心理有问题 / 心理疾病 | 最近状态不太好 |
| 患者 / 病人 | 参与者 / 同学 |
| 治疗 / 干预 | 活动 / 一起聊聊 |
| 筛查 / 评估 | （干脆不要做） |
| 正能量 / 负能量 | 情绪 |

## 图片与配色

- 避免：抱头痛苦的人、悬崖、破碎玻璃、黑白雨窗——这是"恐吓式劝退"，只会让人不敢点。
- 避免：全员大笑的摆拍——不真实。
- 可以：空椅子、桌上的热茶、走廊的窗、摊开的笔记本。安静但不绝望。

## 最后一遍自查

发布前逐条问：

1. 有没有哪句话在**承诺结果**？
2. 有没有哪句话在**替读者下定义**？
3. 有没有哪句话，如果读者正处在低谷，看完会更难受？
4. 页面里有没有一个地方，能让他**立刻找到人**？

四条都过了，再发。
